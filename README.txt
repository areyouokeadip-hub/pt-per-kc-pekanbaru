WEBSITE PT PER - STARTER PROJECT

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder website_pt_per melalui Visual Studio Code.
3. Buka file index.html di browser, atau gunakan ekstensi Live Server.
4. Untuk logo, letakkan file logo resmi PT PER di folder assets dengan nama:
   logo-pt-per.png
   (Gunakan file logo resmi dari perusahaan; jangan gunakan logo contoh/fallback.)

ISI FOLDER
- index.html : struktur halaman dan menu
- style.css  : desain Melayu Riau modern dan responsif
- script.js  : navigasi menu dan kalkulator simulasi
- assets/    : tempat logo resmi PT PER

CATATAN PENTING
- Ini adalah prototipe frontend. Belum menggunakan database, login admin, atau backend.
- Data lokasi/kontak dan ringkasan produk diisi sebagai informasi awal berdasarkan informasi publik yang tersedia di website PT PER. Mohon verifikasi kepada perusahaan sebelum dipublikasikan.
- Kalkulator memakai metode anuitas dengan bunga tahunan yang dapat diubah pengguna. Ini bukan perhitungan resmi PT PER dan belum mencerminkan semua akad/biaya pembiayaan.
- Rumusan visi dan misi pada halaman Tentang Kami merupakan teks konsep, bukan kutipan resmi.
- Logo resmi belum disertakan karena perlu memakai berkas logo asli yang disetujui perusahaan.
